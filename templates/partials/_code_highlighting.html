{% load static %}{% comment %} Syntax colours for every code block on the site, from one place. Included once, at the end of templates/base.html. It does nothing on a page without code, so those pages load no highlighter at all. On a page with code it loads the Prism core and only the language components that page uses, straight from static/vendor/prism (assets/vendor.toml pins every file), and colours each block. The colours are the token palette in static/css/tailwind-input.css. Code written by a script after the page loads (the free tools' results) is coloured by calling window.highlightCode(element) once it is in the page. A button with data-copy inside a .code-card copies that card's code. See .github/instructions/code-syntax-highlighting.instructions.md. {% endcomment %}
